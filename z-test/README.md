# Z-тест: нормальное распределение, ЦПТ и конверсия

[Открыть ноутбук **Z-test.ipynb**](./Z-test.ipynb)

Адаптация [открытой лекции Академии аналитиков Авито](https://github.com/avito-tech/applied_statistics/blob/main/Z-test.ipynb). Сохранены исходные объяснения, примеры и ход рассуждений; обновлены графики и устранено дублирование функции.

## Что внутри

1. Нормальное распределение: параметры, плотность, вероятности и квантили.
2. Центральная предельная теорема: примеры и визуализации.
3. Z-критерий: p-value, сравнение с биномиальным тестом, поправка 0.5.
4. Практический блок проверки **одной конверсии**.

## Как запустить

Открой ноутбук в Google Colab или Jupyter, измени последний блок **ВВОД ДАННЫХ** и нажми **Run All**.

| Параметр | Что значит |
|---|---|
| N | размер выборки |
| SUCCESS_CNT | количество успехов |
| P0 | предполагаемая вероятность успеха при H0 |
| ALTERNATIVE | greater, less или two-sided |
| ALPHA | уровень значимости (например, 0.05) |
| USE_CONTINUITY_CORRECTION | применять поправку 0.5 в нормальном приближении |

Выводятся наблюдаемая конверсия, Z-статистика, приблизительное и точное p-value и решение по точному биномиальному тесту. Пример из лекции: 19 успехов из 30 при H0: p = 0.5 и H1: p > 0.5; точное p-value ≈ 0.10024, поэтому на уровне 5% H0 не отклоняется.

Для локального запуска:

python -m pip install numpy scipy matplotlib seaborn jupyter

**Границы применимости:** это проверка одной биномиальной доли, а не двух групп A/B. Для малых выборок предпочтителен точный биномиальный тест. Z-приближение требует обоснованных предпосылок; поправка на непрерывность применима к дискретным подсчётам успехов.
