# Applied Statistics

Личный учебный репозиторий по прикладной статистике: код, визуализации и короткие пояснения к основным статистическим методам.

## Разделы

### Statistical test: comparison of the critical region and the p-value
Правосторонний биномиальный критерий для проверки гипотезы о вероятности успеха.

В разделе:
- биномиальное распределение при `H0`;
- критическая область;
- расчёт `p-value`;
- сравнение `p-value` с уровнем значимости `alpha`;
- визуализация распределения, критической области и наблюдаемого значения;
- итоговое решение: `reject H0` / `do not reject H0`.
