# Applied Statistics · Прикладная статистика

Личный справочник по статистике: **вводишь свои параметры → получаешь числа → при желании строишь графики**. Каждый раздел — отдельная задача; в папках лежат инструкции и готовые ноутбуки.

**[Инструкция к новому разделу →](./power-mde-confidence-intervals/README.md)** — какие файлы за что отвечают, куда вводить значения и как включать/сохранять графики.

## Быстрый старт

1. Открой нужный `.ipynb` в Jupyter, VS Code или Google Colab.
2. Установи библиотеки из [`requirements.txt`](./power-mde-confidence-intervals/requirements.txt) (инструкция внутри папки).
3. В блоке **ВВОД ДАННЫХ** измени числа после `=`, например `P0 = 0.50` и `P_ALT = 0.60`.
4. Выполни **Run All** — получишь результаты и графики прямо в ноутбуке (`SHOW_PLOTS = True` уже установлено).

> На GitHub `.ipynb` можно читать и видеть сохранённые результаты, но нельзя запускать вычисления без Jupyter / Colab. Если графики не видны, открой [примеры PNG](./power-mde-confidence-intervals/figures/) или запусти ноутбук.

## Область применения

Новый раздел воспроизводит **одновыборочную** постановку из [лекции Stat power.ipynb Академии аналитиков Авито](https://github.com/avito-tech/applied_statistics/blob/main/Stat%20power.ipynb). В нём проверяется одна доля успехов относительно фиксированного значения `p0`. Это **не** готовый калькулятор стандартного A/B-теста двух независимых групп.

Материалы исходной лекции использованы с указанием авторства; код переработан в практические функции с комментариями и проверкой входных данных. Существующий раздел про p-value и критическую область **не изменялся**.
