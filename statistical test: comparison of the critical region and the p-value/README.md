# Binomial Hypothesis Testing

Правосторонний биномиальный критерий для проверки гипотезы:

- `H0: p = p0`
- `H1: p > p0`

## Что делает ноутбук

Ноутбук:
- задаёт биномиальное распределение при `H0`;
- находит критическое значение через `ppf`;
- рассчитывает `p-value` через `cdf`;
- сравнивает `p-value` с уровнем значимости `alpha`;
- выделяет критическую область на графике;
- показывает наблюдаемое значение `Q`;
- выводит итог: `reject H0` или `do not reject H0`.

## Интерпретация

Если `p-value <= alpha`, наблюдаемый результат считается достаточно редким при справедливости `H0`, поэтому `H0` отвергается.

Если `p-value > alpha`, оснований отвергать `H0` недостаточно.
